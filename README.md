# My Very First Project

A simple, responsive landing page for **Frontend Simplified** — a site for learning frontend development, from absolute beginner to pro.

🔗 **Live site:** https://mamalgamerrtx.github.io/MyVeryFirstProject/

## Features

- **Navigation bar** with logo and links to each section
- **Hero section** with a headline, tagline, and "Start now" call-to-action
- **About section** with text and image
- **Discord section** promoting the community
- **Contact form** with email and message fields
- **Footer** with navigation links and copyright

## Built With

- HTML5
- CSS3
